# SystemWork Frontend

This project is a React application built with [Vite](https://vitejs.dev/) and TailwindCSS.
It provides the frontend for the SystemWork employee management system.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file with the API endpoint:
   ```bash
   VITE_API_URL=http://your-api-url
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Production build

Generate an optimized build with:
```bash
npm run build
```

## Linting

Run ESLint:
```bash
npm run lint
```

(An ESLint configuration is required for this command to succeed.)
